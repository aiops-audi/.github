# aiops-audi/.github

Standalone public org profile and **public design assets** for Audi AIOPS.

- `profile/README.md` — public org profile (branding only), shown on the organization page.
- `profile/assets/` — public SVG branding assets used by the profile.

The profile and its assets are maintained entirely in this repository; no separate private profile repository is required.

Do not put private repository names, links, descriptions or internal details here — everything in this repo is public. A members-only repository catalog is intentionally not part of this public profile.

Images are referenced via jsDelivr pinned to a commit of `aiops-audi/.github` (`cdn.jsdelivr.net/gh/aiops-audi/.github@<commit>/...`) because `raw.githubusercontent.com` is blocked by the corporate Zscaler proxy and `@main` is cached for hours. After changing an SVG in this repository, push it, then replace the commit hash in `profile/README.md` with the new commit.

Palette: `#080b20` navy · `#f1f4ff` type · `#00e7ff` cyan · `#6035c9` violet glow.
